Project Overview

Lifestyle Store is a responsive e-commerce website developed using PHP, HTML, CSS, JavaScript, and Bootstrap.

The project provides an online shopping platform where users can browse products, register/login, and purchase products easily through a simple and user-friendly interface.

User Registration & Login
Responsive Design
Product Listing
